## 0. 一句话结论

阈值问题不能靠"这是文献惯例"打发，因为 **10/7/4 不是文献惯例，是我们自己定的**。
唯一站得住的答法是三件事同时给：

1. **分数是数据，段是标签**——S8 已逐例列 0–12 原始分，读者可自行改带；
2. **极性稳健、标签不稳健**——所有 12 例的正/负判决在分段扰动下不变（余量 2–7 分），
   但 3 例 Grade A 的 A/B 标签会随 A 边界 ±1 翻转，这一点必须自己先说；
3. **三条边界不是随手数字**——在 43,200 次基准 ROC 上，A=10 对应 FPR 3.6%、
   B=7 对应 10.3%、C=4 对应 17.5%，是三个嵌套的假阳性水位。

## 1. 先把两类阈值分开（这是整个应答的骨架）

| | 识别阈值（identification） | 聚合阈值（aggregation） |
|---|---|---|
| 例子 | P<5e-8、F>10、r²<0.001、PP.H4≥0.80、power≥80%、BH-FDR 0.05 | A≥10 / B≥7 / C≥4、G2 封顶 6、FDR 容差 0.20 |
| 性质 | 继承自领域，改它等于改 MR 的定义 | 我们设计的分段/容差 |
| 应答方式 | 给出处，不辩解（Burgess 2013；Giambartolomei 2014；Auton 2015；Benjamini–Hochberg） | 给稳健性证据 + 给推导，**不声称是惯例** |
| 若被挑战 | "这些是方法学定义，不是本文主张" | "这些是报告约定，且不承载结论" |

> 评审合并成一句"阈值都任意"时，**先拆成这两栏再回答**。混着答必输。

## 2. 已算出的弹药（本轮即可交付）

### 2.1 单点扰动（12 例，S12.1）

| 移动 | 变段例数 | 极性翻转 | 具体 |
|---|---|---|---|
| A：10→9 | 1 | 0 | Education→T2D B→A |
| A：10→11 | 3 | 0 | 三个 A 例全降 B |
| B：7→5 | 3 | **3** | BMI→Stroke / HDL→CAD / Depression→AD C→B |
| B：7→6 / 8 | 0 | 0 | 无例落在 6–7 分 |
| C：4→5 | 1 | 0 | Insomnia→AD C→D（仍是负判决） |
| G2 封顶 4/6/8/取消 | 0 | 0 | 本队列无例触发 |

**读法**：唯一有实质风险的是 B 边界——把 7 下移到 5，三例 5 分案从 C 跳到 B。
这三例恰好是全表最弱证据组，正文对它们没有任何具体主张，只在分布计数里出现。

### 2.2 全枚举（220 种单调四段划分，S12.2）

| 案例 | 分数 | 段 | 同极性（全部 220） | 同极性（非退化 56 种） | 极性余量 |
|---|---|---|---|---|---|
| 三例 A | 10 | A | 95.5% | 100% | 4 |
| Insomnia→AD | 4 | C | 76.4% | 89.3% | 3 |
| Height→CAD | 8 | B | 76.4% | 89.3% | 2 |
| 三例 5 分 | 5 | C | 63.6% | 71.4% | 2 |
| 三例 D | 0 | D | 100% | 100% | 7 |

**读法**：主案 Insomnia→AD 要翻成 A/B，需要把 A/B 边界从 7 下移 3 分（到 4），
即 A+B 两段合占 13 个分值中的 9 个——那已经不是四段量表了。

### 2.3 基准 ROC 定位（S12.4，43,200 次）

| 切点 | FPR | TPR(β=0.15) | Youden J |
|---|---|---|---|
| 4（C 边界） | 0.175 | 0.929 | 0.652 |
| 7（B 边界） | 0.103 | 0.875 | 0.598 |
| 10（A 边界） | 0.036 | 0.753 | 0.496 |
| 11 | 0.000 | 0.736 | 0.512 |

A 边界正好是"FPR≤5%"的操作点（pooled 与 directional 两个 regime 都是 10；balanced 需 11）。
10→11 的取舍是 2 个点灵敏度换 3.6 个点假阳性——**曲线在此处是平的**，
这正是边界该有的性质；反过来也说明"为什么不是 11"有量化答案。

> ⚠️ 诚实性约束：这是**事后一致性核验**（评审提出后我们才做的），
> 不能写成"当初就是按 FPR≤5% 定的"。措辞必须是 "we checked post hoc whether…"。

## 3. 三种追问形态与对应答法

### 形态 A：「10/7/4 为什么不是 11/8/5？」（最可能）

三句话，按顺序：

1. 分段是报告约定，不是估计量；本文所有结论只依赖**分数与极性**，不依赖段位。
2. S12.1/S12.2：单点移动最多改 3 例段位、0 例极性；全枚举下主案极性余量 3 分。
3. S12.4：三条边界在基准 ROC 上分别落在 17.5% / 10.3% / 3.6% 假阳性水位，
   移动任一条都只是换一个更松或更严的水位，不存在"正确"的水位。

**不给**：一个"改过的更好阈值"。任何新阈值同样任意，等于自认旧阈值错。

### 形态 B：「那就别给 grade，只报连续分数」

**接受一半**：同意把"分数为主、段为辅"写进 Methods，S8/Fig 5 已同时给两者。
**不接受全部**：框架的用途是分诊，分诊必须有离散输出；取消段等于取消框架。
落点：段保留但标注为"报告约定"，并声明边界附近（±1 分）的段位是暂定的。

### 形态 C：「换个阈值，你的结论会变吗？」

直接给数字，且**先给会变的部分**：

- 会变：3 例 Grade A 的 **A/B 标签**（A 边界 10→11）；Education→T2D 的 B/A 标签；
  Insomnia→AD 的 **C/D 标签**（C 边界 4→5，仍是负判决，措辞从"共享负债"变成"被证伪"）。
- 不会变：全部 12 例的**正/负极性**；主案"无独立上游因果"这一判决；
  三个正对照的"支持有向因果"这一判决。

## 4. 若编辑要求"必须彻底解决"

提出把阈值显式化为**决策规则**，而不是辩解：

> 在基准 ROC 上给定目标假阳性率 α，边界取使 TPR 最大的最小分数。
> 我方可给出 α = 5% / 10% / 20% 三档对应的 (A, B, C) 三元组，并把默认档
> （5% / 10% / 约 18%）与本文所用值对齐；用户可按自己的容忍度换档。
> 下一版预注册所用档位。

这既回应"任意"（任意→可参数化），又不动任何现有结论（默认档即现值）。
红线：**不要**承诺改成某个"最优阈值"——最优依赖损失函数，会打开新战场。

## 5. 措辞红线

| ❌ 不能说 | ✅ 应说 |
|---|---|
| "这些阈值是领域通用惯例"（对 10/7/4 说谎） | "识别阈值是惯例，聚合阈值是我们的报告约定" |
| "敏感性分析显示完全稳健" | "极性全部稳健（余量≥2 分）；3 例的 A/B 标签不稳健，已声明" |
| "我们已改用最优阈值" | "边界对应三个可命名的假阳性水位；换档不改变极性" |
| "grade 只是描述性的"（与框架用途矛盾） | "score 是数据，grade 是报告约定，二者并列给出" |

## 6. 待决策（P0，与阈值问题同源）

🔴 **基准 Table 2 与已发布规则不一致**：`sim_framework_operating_chars.py` 用的是
纯加法总分，**没有施加 G2 封顶 6**。施加后 4,363/43,200（10.1%）重复由 B 降 C，
全是真效应，导致：

| regime | sens(β=0.15) | sens(β=0.08) | FDR（1/3 null） | FDR（1/2 null，重加权） |
|---|---|---|---|---|
| none | 0.973 → **0.878** | 0.506 → **0.216** | 0 → 0 | 0 → 0 |
| balanced | 0.847 → **0.724** | 0.527 → **0.376** | 0.083 → **0.100** | 0.15 → **0.18** |
| directional | 0.804 → **0.692** | 0.545 → **0.408** | 0.128 → **0.151** | 0.22 → **0.26** |

特异性与 P(Grade A) 完全不变（封顶只压 B→C）。

两条路：

- **(a) 重算**：Table 2 / S9 / Fig 2 / Results 数字 / 给 R1-4 的答复同步改。
  优点：规则与计算真正一致，正好堵死 R1-1「规则不统一」的延伸追问。
  代价：约 5 处文本 + 1 图重绘；"灵敏度 0.97"这个亮点会变成 0.88。
- **(b) 披露**：Methods + Table 2 脚注写明"基准评估的是加法规则，封顶仅用于实证队列"。
  优点：改动小。缺点：评审刚追问过"代码与描述不一致"（R1-2），这是同一类缺陷，
  再被指出一次代价远大于现在重算。

**建议 (a)**，并在 R1-1 答复里主动写出这一条——自己纠错比被指出强得多。
