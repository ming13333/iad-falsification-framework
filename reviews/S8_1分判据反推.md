# S8 六门「1 分」判据反推报告

> 2026-10-27 · 依据：`code/sim_framework_operating_chars.py::grade_framework()` L124–L170、`课题设计阶段/Supplementary_final/S8_twelve_case_validation.csv`、`code/interrater_reliability.py`
> 目的：R1#1 要求「一张统一评分表，含部分得分、决定性失败、冲突、不可用/功效不足」。本报告反推 1 分的确切判据，并给出可核验性与代价。

---

## 0. 一句话结论

**1 分判据确实存在，而且是写死在模拟代码里的五条明确规则，不在稿件的任何一张表里。** 所以 R1#1 要的东西不是"编出来"，是把代码搬进 Table 1。

但反推同时暴露两件事：

1. **S8 的 12 例手工评分与这五条代码规则不是同一套。** 六门里有五门（G1–G5）连判定所需的统计量都没有记录，**只有 G6 能当场核验，而该门唯一那格 1 分是错的**。
2. **G2 的两格自相矛盾**（BMI→T2D 得 2、HDL→CAD 得 1，但在 S8 记录的列里两者证据模式相同），任何规则都无法分开 —— 这说明至少一格记错，或缺一个决定性统计量（Cochran Q）。

## 1. 反推出的六条规则（代码原文 + 释义）

| 门 | 代码行 | 代码原文 | 1 分的**确切**含义 | 0 分 |
|---|---|---|---|---|
| G1 | L127 | `2 if (p1 < 0.05 and abs(b1) > 1e-4) else (1 if p1 < 0.2 else 0)` | **0.05 ≤ P < 0.20**，方向不限（"提示性信号，保留待伪证"） | P ≥ 0.20；且 **L1=0 触发级联**，六门全部归零、直接判 D |
| G2 | L140 | `2 if (p2 < 0.05 and p_int > 0.05) else (1 if p2 < 0.05 else 0)` | **clump 后仍显著，但 MR-Egger 截距 P ≤ 0.05**（检出方向性多效性） | clump 后不显著（含 clump 后翻转 → 决定性失败） |
| G3 | L145 | `2 if (frac_blocks >= 0.5 and n_eff >= 5) else (1 if frac_blocks >= 0.3 else 0)` | **信号只覆盖 30%–50% 的 LD 块**（定位受限，非全基因组弥散） | 覆盖 < 30%；或 n_eff < 5 |
| G4 | L157 | `2 if (p2 < 0.05 and loo_spread < 0.5) else (1 if p2 < 0.05 else 0)` | **clump 后显著，但留一法（LOO）不稳定**，`loo_spread ≥ 0.5` | clump 后不显著 |
| G5 | L162 | `2 if (p5x < 0.05 and p5y < 0.05) else (1 if (p5x < 0.05 or p5y < 0.05) else 0)` | **两步中介只有一步显著**（通路只走通一半） | 两步都不显著 |
| G6 | L167 | `2 if (p6 < 0.05 and consistent) else 0` | **不存在 1 分档，恒二元** | 方向不一致，或检验不显著 |

> ⚠️ 关键：**G4 的代码规则与 Table 1 正文根本不是同一件事。** 正文说 G4 用 MVMR（条件 F>10），代码用的是**留一法离散度**这一代理，且注释自承 `# Use leave-one-out robustness as direct-effect proxy`。这正是 R1#2 所指"G4 用 leave-one-out 变异（而非 MVMR）"。

## 2. 可核验性：六门里只有一门能当场核对

| 门 | S8 中 1 分数 | 判定所需统计量 | S8 是否记录 | 结论 |
|---|---|---|---|---|
| G1 | 3 | **clump 前** IVW 的 P | 🔴 否（`IVW_P` 是 clump 后） | 不可核验 |
| G2 | 4 | Cochran Q 的 P + MR-Egger **截距** P | 🟡 只有一列 `Egger_P`，语义未标注 | 不可核验 |
| G3 | 4 | LD 块覆盖比例 / 共定位区域数 | 🔴 否（无 rg 列、无 PP.H4 列） | 不可核验 |
| G4 | 6 | 条件 F + MVMR 直接效应 | 🔴 否 | 不可核验 |
| G5 | 2 | 两步 MR 各自的 P | 🔴 否 | 不可核验 |
| G6 | 1 | 无需（恒二元） | ✅ — | **可核验，且该格错** |

**为什么确认 `IVW_P` 是 clump 后**：Insomnia→AD 的 `IVW_beta=-0.128, IVW_P=0.52`，与项目已冻结的 clump 后结果（β=−0.130, P=0.52）一致；而 clump 前是 β=+0.10, P=0.0009。**L1=2 只能由 clump 前显著性解释** —— 说明这两列记录的是两个不同的估计，但表里只有一个 `IVW_P` 列。

## 3. 反推出的三处硬矛盾

### 3.1 G6：唯一可核验的门，唯一那格是错的

`HDL→CAD L6 = 1`。代码 L167 与 Table 1 正文（"Underpowered tests … assign no points"）**都规定该门没有 1 分档**。
→ 改 1→0：HDL 总分 6→5，仍为 **C，等级不变**。

### 3.2 G2：两格无法用同一规则分开

| 案例 | clump 后 P | WM P | Egger_P | S8 给分 |
|---|---|---|---|---|
| BMI→T2D | 1.4e-03 ✅ | <1e-3 ✅ | 0.136 | **2** |
| HDL→CAD | 8.9e-04 ✅ | 0.003 ✅ | 0.891 | **1** |

两者在 S8 记录的所有列上模式相同，却一个 2 分一个 1 分。**任何仅基于这些列的规则都无法分开** → 或者至少一格记错，或者判分依赖了未记录的 Cochran Q。后者最可能（HDL 的工具多、异质性高），但必须补列才能证明。

### 3.3 `Egger_P` 一列混装两种量

- `Education→T2D` 备注明写 **"Egger int p=0.036"** → 该行是**截距**。
- 若各列一律按截距解释，则 LDL（4.1e-09）与 Height（0.046）的 L2 应为 **1**，而实际记 **2** → 冲突。
- 若 LDL/Height 是**斜率**，则 HDL 备注"IVW sig but Egger null"（斜率零）也说得通 → 该行是斜率。

**结论：同一列被填了两种量。** 必须拆成 `Egger_intercept_P` 与 `Egger_slope_P` 两列再回原始输出核对。

## 6. 对照：若全按「代码规则」（G2=α）会付出什么

| 案例 | 原分/级 | 新分/级 | 后果 |
|---|---|---|---|
| LDL→CAD | 12 A | 11 A | 无影响 |
| Height→CAD | 10 A | 9 **B** | 失去一个 A 级正例（R2 原本也给 B，等于把争议判给 R2） |
| HDL→CAD | 6 C | 7 **B** | 🔴 **破坏 R1#10 引用的 HDL 案例**（正文用它演示"框架正确地把脂质假说降级"），B 级等于说框架没降级 |
| BMI→Stroke | 5 C | 6 C | 无影响 |
| Depression→AD | 5 C | 6 C | 无影响 |

**所以 G2 不建议采用纯代码规则 α。** 这不是为保等级，而是因为 α 比正文更宽松（多效性只扣 1 分），而 HDL→CAD 恰恰是"多效性校正后效应消失"的教科书案例 —— 给 2 分在科学上是错的。

## 7. Table 1 英文成稿（可直接替换）

> **Scoring.** Each gate awards **2** points when its pre-specified primary criterion is met, **1** point when the primary criterion is met only partially in the sense defined below, and **0** otherwise. A gate scoring 0 on G1 terminates scoring: the trait pair receives Grade D with a total of 0, because no association exists to falsify. Gates that cannot be evaluated (data unavailable) score 0 and are flagged as non-evaluable; they never receive partial credit.
>
> **G1 (association).** 2 if the unclumped IVW estimate is nominally significant (P<0.05) in the claimed direction; **1 if 0.05≤P<0.20 in the claimed direction** (suggestive signal retained for falsification); 0 if P≥0.20, or if the estimate lies opposite to the claim.
>
> **G2 (robustness).** 2 if the clumped IVW estimate remains significant in the claimed direction with no directional pleiotropy (MR-Egger intercept P≥0.05), no excess heterogeneity (Cochran Q P≥0.05), and a concordant weighted-median estimate; **1 if the clumped estimate remains significant in the claimed direction but at least one of these three robustness criteria fails**; 0 if the clumped estimate is non-significant or reverses direction, which is a decisive failure regardless of the unclumped result.
>
> **G3 (genetic architecture).** 2 if genetic correlation is directionally concordant (or null) together with locus-specific colocalization (PP.H4≥0.80) at the expected region, and the shared signal spans more than one region; **1 if the shared signal is confined to a single region without genome-wide correlation** (locus-restricted liability); 0 if the architectural evidence contradicts the claim.
>
> **G4 (direct effect).** 2 if the MVMR direct effect is significant in the claimed direction with conditional F>10; **1 if the direct effect is estimable (conditional F>10) but attenuates to non-significance, or reverses sign, after adjustment**; 0 if conditional F≤10 or no association exists.
>
> **G5 (biological mediation).** 2 if both steps of the two-step MR are significant and the FDR-corrected indirect effect is consistent with the claim; **1 if only one of the two steps reaches significance** (partial pathway); 0 if neither step is significant.
>
> **G6 (external validation).** 2 if the direction is concordant in an independent-ancestry cohort with achieved power ≥80%; **0 otherwise** — underpowered replications (power<80%) are reported as directional screening and receive no points.

**必须同时加的一句披露**（回应 R1#2）：*In the simulation, G2 was evaluated with the MR-Egger intercept criterion only, and G4 used leave-one-out stability as a proxy for the direct effect; the heterogeneity, weighted-median and multivariable criteria were applied in the empirical analyses.*
