# Supplementary Table S12. Threshold robustness of the scoring rule

Cut-off values in a graded rubric are choices, not estimates. This table quantifies what those choices change: (i) which band each of the twelve validation cases occupies if a single cut-off is moved by one point; (ii) band and polarity stability over every monotone four-band partition of the 0-12 scale; (iii) where the rubric's cut-offs sit on the score's ROC in the 43,200-replicate benchmark; and (iv) whether the decisive-failure cap can bind in this cohort. Generated by `code/threshold_robustness.py`.

## S12.5 Effect of the decisive-failure cap in the benchmark

The archived benchmark script applied the additive total and never applied the decisive-failure cap, so the operating characteristics first submitted described a rule the manuscript no longer used. The cap has since been added to the scoring function and the benchmark re-run with the same seed; the gate scores are bit-identical and 4,363 of 43,200 replicates (10.1%) are regraded from Grade B to Grade C, all of them with a true non-zero effect.
