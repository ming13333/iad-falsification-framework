## 1. 项目一句话定位

> **研究问题**：失眠与阿尔茨海默病（AD）之间的因果方向、时序与蛋白机制是什么？
> **方法组合包**：双向 MR + 共定位 + 血浆蛋白两步中介 + 多状态发病顺序（+ 并行 跨祖先验证）。
> **为什么能冲高分**：不依赖湿试验/临床治疗数据，靠「多方法三角验证」把证据从「相关/单方法因果」升到「多源一致的因果」；且该五要素组合包无人同时交付过。
> **立题一句话**（用于标题/摘要）：
> "失眠与阿尔茨海默病之间的因果方向、时序与蛋白机制是什么？——一项基于双向 MR、共定位、血浆蛋白中介与多状态发病顺序模型的跨祖先研究。"

## 4. 研究设计总览（三角验证）

- **G1 双向 MR + 共定位**：定性「方向」。失眠→AD 正向 MR + AD→失眠 反向 MR；IVW 主、MR-Egger/加权中位数/众数/MR-PRESSO/留一法敏感；Steiger 方向加固；coloc 共享因果变异（PP.H4>0.8）。
- **G2 血浆蛋白两步中介**：落地「机制」。Step1 失眠→蛋白 pQTL（b1）× Step2 蛋白→AD（b2）= 中介效应；~2923 蛋白 → FDR；coloc 复核 top 蛋白；反向（AD→蛋白→失眠）证伪。
- **G4 多状态顺序**：刻画「时序与预后」。UKB 个体级 illness-death 模型（S0 健康→S1 仅失眠→S3 共病 vs S0→S2 仅 AD→S3）；msm 包；对比 1→3 vs 2→3 路径与到达 S3 后分层生存。
- **三角验证**：G1 方向 + G2 机制 + G4 时序是否一致收敛。
  - 一致 ⇒ 失眠在 AD 上游，可因果、可机制的靶点。
  - 不一致 ⇒ 纠偏型结论（失眠或为 AD 临床前标记）——同样是高价值产出。
- **G3 跨祖先**（并行）：CHARLS / BBJ / 东亚 UKB 子集复制 G1/G2，正面怼 generalizability。

## 5. 数据与工具清单（关键常量）

### 数据库 / GWAS 汇总统计
| 角色 | 数据集 | 规模 | 备注 |
|------|--------|------|------|
| 失眠（暴露） | Jansen 2019 *Nat Genet* | ~1.3M、~110k 病例（EUR） | IEU/OpenGWAS；运行前用 `ieugwasr::gwasinfo` 复核 ID |
| AD（结局） | Bellenguez 2022 *Nat Genet* | 111,326 病例（EUR） | 或 Kunkle/IGAP 作独立复制 |
| 蛋白 pQTL（中介） | UKB Pharma Proteomics Project | ~54,219 人、Olink ~2,923 蛋白 | 需确认 panel 覆盖 GFAP/NfL/炎症因子 |
| 个体级（G4） | UKB | 字段 2245/2255（失眠自评）+ ICD-10 G47.0（失眠）+ F00/G30（AD）+ 死亡登记 + APOE ε4 | 需 UKB 数据权限申请 |

### R 包
- CRAN：`TwoSampleMR`、`ieugwasr`、`msm`、`mstate`、`survival`、`dplyr`、`data.table`、`ggplot2`
- Bioconductor：`coloc`
- 可选：`MR-PRESSO`（`devtools::install_github("rondolab/MR-PRESSO")`）

### 关键阈值（`code/00_config.R` 中定义）
- clump r²=0.001、kb=10000、MAF≥0.01、F>10（敏感可升 20）
- coloc PP.H4 > 0.80
- MR α=0.05；G2 蛋白 FDR<0.05；G4 双路径对比 α=0.05
- 协变量（G4）：age、sex、education、depression、apoe_e4、hypnotic_use

- 失眠 UKB 自评弱 → 已用 ICD 敏感性 + 遗传工具（独立于测量）。

- 全欧裔（G1/G2）→ 留 G3 跨祖先复制作并行增量。
- "可改变靶点"需干预研究验证 → 诚实声明，不夸大（呼应 STORM 历史学家视角：警惕"可改变生活方式防痴呆"模板）。
- MR 生死线敏感性：MR-Egger 截距、MR-PRESSO 离群、留一法、Steiger、异质性 Q。
