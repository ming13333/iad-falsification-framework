## 二、后续步骤分解（详细说明 + 复杂程度）

> 说明：你消息中的"下面的步骤"未附具体清单，此处按课题 SOP（Workflow A 全流程）的剩余路径拆解。若你指的是另一份清单，请把清单贴出，我按那份重拆。

### 步骤 0（前置补做）：Phase 1 收尾 — OSF 预注册 + 00b 样本重叠核验
- **详细说明**：补做两项 Phase 1 缺口。① 由写作/审计角色产出 OSF 预注册文档（锁定暴露=失眠、结局=AD、协变量、方法顺序、敏感性清单、阈值），锁定分析计划防 p-hacking。② 跑 00b_verify_gwas.R 思路的样本重叠核验：确认 Jansen 2019 / Bellenguez 2022 的 IEU ID 与样本量、Jansen↔Bellenguez 的 UKB 样本重叠比例、UKB-PPP panel 是否覆盖 GFAP/NfL/炎症因子。
- **复杂程度**：低-中（文书 + 一次核验脚本，无新建模）
- **依赖**：无（可立即做）
- **产出**：预注册链接/文档 + 数据核验清单（含重叠比例）
- **备注**：范审明专家包若仍不可用，主理人按"正式报告供复核"方式代出预注册草稿

### 步骤 1：G1 恢复重跑（精简版）
- **详细说明**：在 ASCII 副本脚本加 `RUN_MR_PRESSO <- FALSE`（或等价 guard），跳过 MR-PRESSO 这一非必需敏感性分析；其余双向 MR（IVW/Egger/加权中位数等）+ 区域 coloc + MRlap/cause 正常跑。重跑后落盘 `results/`（RDS/CSV/图）。
- **复杂程度**：低-中（改动小；重跑耗时约 30–60 分钟，harmonize 已验证快）
- **依赖**：步骤 0 的 GWAS ID 锁定（可并行）；当前 clean 文件就绪
- **风险**：coloc 区域版若对每 lead SNP 重复读全量 GWAS 仍可能偏慢（脚本设计为每方向 fetch 一次，通常可接受）
- **产出**：G1 双向 MR 结果表 + coloc PP.H4 + 敏感性结果

### 步骤 2：G1 重叠校正收尾 — MRlap / cause
- **详细说明**：对双向 MR 做 UKB 样本重叠的因果方向校正。用 MRlap（需 LD 参考面板）和 cause（似然比方向检验）区分"失眠→AD"与"AD→失眠"哪条是真实因果方向，排除样本重叠导致的假阳性。
- **复杂程度**：中（LD 面板接入、cause 模型拟合、结果解释需谨慎；MRlap 在受限环境偶有依赖问题）
- **依赖**：步骤 1 的 G1 方向结论
- **产出**：方向校正后结论 + MRlap/cause 报告段

### 步骤 3（Phase 3）：G2 血浆蛋白两步中介
- **详细说明**：基于 G1 确定的因果方向，用 UKB-PPP 蛋白 pQTL 做两步 MR 中介分析。第一步 暴露（失眠）→ 蛋白；第二步 蛋白 → 结局（AD）；乘积法估中介效应，FDR 校正筛选显著蛋白；对 top 候选做 coloc 复核共定位；再做反向两步 MR 证伪。
- **复杂程度**：高（pQTL 接入、两步 MR 多重检验、FDR、coloc 验证、反向证伪，方法链长且易踩假设陷阱）
- **依赖**：步骤 2 的因果方向
- **产出**：蛋白级中介效应表（FDR 校正）+ top coloc + 反向证伪结果

### 步骤 4（Phase 4）：G4 多状态发病顺序
- **详细说明**：用 UKB 个体级纵向数据，建多状态模型刻画"失眠先发→AD" vs "AD 先发→失眠"的转移强度 q、累积发病率、分层生存预后。这是三角验证的临床时序端。
- **复杂程度**：高（最大外部依赖：需 UKB 个体级数据权限审批；多状态模型、转移强度估计、分层生存分析）
- **依赖**：UKB 数据权限（当前未获批，是主要门控）；可与步骤 1–3 并行准备
- **产出**：转移强度 q、1→3 vs 2→3 累积发病、分层生存预后

### 步骤 5（Phase 5）：三角验证 + 写作 + STORM 审计
- **详细说明**：把 G1（遗传因果）、G2（分子机制）、G4（临床时序）三独立证据源汇总，判断是否收敛到同一结论（三角验证）。产出手稿草稿（Fig1–5 / Table1）与 STORM 风格批判性审计表（多视角审查证据强弱与盲区）。
- **复杂程度**：中（综合写作 + 审计表；无新统计，但需严格逻辑收敛判断）
- **依赖**：步骤 1–4 全部结论（经主理人中转）
- **产出**：三角验证汇总 + 手稿草稿 + STORM 审计表

### 步骤 6：终报汇编 + G3 跨祖先复制（升 A 缺口）
- **详细说明**：主理人汇编研究结论、三源收敛判定、升 A 级证据缺口；规划下一步 G3 跨祖先复制（CHARLS / BBJ / 东亚 UKB），提升泛化性与证据等级。
- **复杂程度**：中-高（外部队列数据获取与跨祖先 MR 复现）
- **依赖**：步骤 5
- **产出**：最终报告 + G3 复制方案
