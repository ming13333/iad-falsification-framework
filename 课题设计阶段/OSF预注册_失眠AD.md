## 0.5 Revision Note（2026-08-02 · 待 OSF 冻结时发布）

> **性质**：本文件为 Phase 1 前置计划文书。截至 2026-08-02，全部主分析（G1 双向 MR+共定位+CAUSE+MRlap、LDSC、G2 蛋白中介、教育 PheWAS-MR、MVMR、C1 代谢物中介、EA 跨祖先复制）已产出。**结果与原主假设 H1（失眠→AD 因果上游）方向不符**，属预注册 §9 定义的"重大偏离"。按 §9 纪律，须在 OSF 冻结后发布本 Revision Note 并说明。
>
> **核心偏离**：原 H1 预期"失眠位于 AD 因果上游"，实际数据显示——(a) 未做 LD-clump 的 UVMR 正向信号（+0.10, p=0.0009）在 clump 后翻转为 null/负，确为工具独立性违例伪迹；(b) clumped UVMR / MRlap / MVMR 三种独立方法均不支持失眠→AD 因果（CAUSE clumped 前向仅边界 p=0.039，与三种方法分歧）；(c) LDSC 全基因组 rg≈0（去 APOE 仍不显著），共享限于 APOE 位点特异性；(d) 最稳健的正向发现是**教育→AD/PD 保护**（β=−0.33~−0.39, p<1e-5），东亚复制方向一致。
>
> **修订后结论**：失眠与 AD 共享以 APOE 为核心的位点特异性遗传负债，失眠非 AD 独立因果上游；教育是跨祖先稳健的保护因子。论文定位由"验证失眠→AD 因果"转为"以失眠-AD 为案例的共病因果三角验证框架（triangulation）示范 + 方法学校准"。
>
> **对预注册纪律的声明**：本偏离非 p-hacking（未为追逐显著而调整分析），而是数据驱动的结论修订；原 H1 在 §2 保留为"被数据推翻的原假设"以供透明对照。OSF 冻结后须将本 Note 作为 Revision Note 附件发布。

## 1. 标题与研究问题

**核心科学问题**：失眠与阿尔茨海默病（AD）之间的**因果方向、发病时序与血浆蛋白中介机制**是什么？本研究以**三角验证（triangulation）**整合三条相互独立、互为补洞的证据链：
- **G1 遗传因果层**：双向 MR + 共定位，定性因果方向；
- **G2 分子机制层**：血浆蛋白两步中介 MR，落地生物学机制；
- **G4 临床时序层**：UKB 个体级多状态模型，刻画发病先后顺序与分层预后。

**可操作研究问题（RQ）**：
- **RQ1（方向）**：失眠是否因果地增加 AD 风险（失眠→AD）？反向（AD→失眠）是否成立？
- **RQ2（机制）**：哪些血浆蛋白介导"失眠→AD"的因果路径？反向（AD→蛋白→失眠）能否被证伪？
- **RQ3（时序/预后）**：真实人群中失眠先发还是 AD 先发占主导？失眠先发的共病者预后是否更差？
- **RQ4（可推广性，G3 后续）**：上述 G1/G2 结论在东亚/华裔/日裔等非欧裔人群中是否复制？

**暴露与结局锁定（不互换）**：暴露（exposure）= 失眠；结局（outcome）= AD。全研究固定此映射，反向 MR 仅作为方向判定的对照，不改变"暴露=失眠、结局=AD"的主叙事。

## 2. 主/备假设（含因果方向预期）

**主假设 H1（方向预期，原预注册 · 已被数据推翻）**：失眠位于 AD 的因果上游——遗传工具支持的因果方向为 **失眠→AD**；AD→失眠为反向对照（预期不显著或显著弱于正向）。
> ⚠️ **修订（2026-08-02）**：实际数据显示失眠非 AD 独立因果上游（见 §0.5 Revision Note）。本 H1 保留为"被数据推翻的原假设"以供透明对照；论文主结论已改为"共享负债 + 教育保护 + 三角验证框架"。

**修订后主结论（数据驱动，非原预注册假设）**：失眠与 AD 共享以 APOE 为核心的**位点特异性**遗传负债（全基因组 rg≈0，可排除|rg|>~0.13）；失眠非 AD 独立因果上游；教育年限是 AD/PD 的稳健保护因子（东亚复制方向一致）。

**备假设 H0（方向不成立）**：双向 MR 显示 AD→失眠与失眠→AD 同等显著（互为因果/反馈环），或反向更强，则"失眠是 AD 可改变前因"叙事被削弱，结论转为"失眠或系 AD 临床前标记"。

**机制假设 H2**：存在至少 1 个血浆蛋白，其间接效应（失眠→蛋白→AD）经 FDR 校正显著，且经 coloc 复核支持共享因果变异（PP.H4>0.80）。

**时序假设 H3**：临床发病顺序上，"失眠先发→共病"路径（S0→S1→S3）的累积发病概率与转移强度高于"AD 先发→共病"路径（S0→S2→S3）；且失眠先发进入共病者全因死亡预后更差。

**三角验证收敛判定（操作化，预先锁定）**：
- **一致收敛（Concordant）** ⇔ 同时满足：
  1. G1 正向 MR IVW P < α 且反向 MR IVW P ≥ α（方向 = 失眠→AD）；
  2. G2 至少 1 个蛋白间接效应 FDR < 0.05 且 coloc PP.H4 > 0.80（机制成立）；
  3. G4 经失眠先发路径（1→3）到达 S3 的累积概率显著高于 AD 先发路径（2→3），且分层生存 HR 的 95% CI 不跨 1（时序成立、预后更差）。
- **不一致（Discordant）** ⇔ 上述三条至少一条不满足。**不一致 ≠ 失败**：本设计将不一致结果（例如 G4 显示 AD 先发为主）作为**纠偏型高分**呈现，直接质疑"可改变生活方式防痴呆"模板，以与一致结果同等篇幅报告，不做选择性呈现。

**不做（诚实边界）**：本研究**不声称"治疗失眠可预防痴呆"**。遗传 MR 与观察性多状态均不提供干预因果；可改变靶点叙事须由随机/准实验干预研究另行验证。讨论中须显式声明此边界，不夸大。

### 3.2 等位基因与效应量约定（锁定）

- **效应等位基因（EA）约定**：所有 GWAS 统一以 `A1 = effect allele`，`A2 = other allele`；报告效应为 **log(OR) per EA**（二分类性状）或 β（连续蛋白）。
- **方向对齐**：失眠→AD 与 AD→失眠 的效应方向均以"EA 增加表型 liability/风险"为正向对齐；蛋白中介 step1/step2 效应同样对齐至"失眠 liability 增加 → 蛋白水平变化 → AD 风险变化"的因果链方向。
- **Harmonization**：使用 TwoSampleMR / ieugwasr 自动链向判定 + 等位基因翻转（allele flipping）统一；**回文 SNP（A/T、G/C）且 MAF > 0.45 者剔除**，避免链向歧义。
- **人群锁定**：G1/G2 主分析限定欧洲裔（EUR）；GRCh37 与 GRCh38 间通过 liftover（如 UCSC/hg19↔hg38）对齐后再共定位，liftover 失败位点排除出 coloc。
- **效应单位**：失眠→AD 报告为"遗传预测失眠 liability 每升高 1 SD 对应的 AD OR"；蛋白→AD 报告为"每 SD 蛋白水平变化对应的 AD OR"；间接效应 ≈ b1 × b2。

### 3.3 GWAS ID 核验与回退策略（锁定，防 ID 漂移）

1. 跑数前**必须**先运行 `code/00b_verify_gwas.R`，联网核验候选 ID 的样本量、人群、instrument 数、GRCh 版本，写 `code/gwas_ids_resolved.json`，`00_config.R` 优先读取。

3. 若 AD ID 无法解析 → 回退至 GWAS Catalog `GCST90012871`（Bellenguez 2022）或 Kunkle 2019（IGAP stage 1）。
4. 实际使用的 ID 与回退理由须在 Methods 中显式记录。

- **归因**：本任务书将 `ukb-b-3957` 标为"Jansen 2019"；既有 `OSF预注册计划.md` 标为"BenElsworth 2018"。**00b 实时 gwasinfo（孟因之，2026-07-30）确认 N=462,341、EUR、trait="Sleeplessness / insomnia"，与 Jansen 2019 UKB 失眠亚样本量（~453–462k）吻合** → 任务书归因获实证支持；原 BenElsworth 2018 标注在 N 量级上一致但上游命名不同。锁定 ID 与 N=462,341 已确认；**Methods 须精确写明该 UKB 失眠 GWAS 的上游来源**（Jansen 2019 或 Ben Elsworth UKB round-2），两说在 N 上一致，不影响分析。

## 5. 计划分析（G1 → G2 → G4 方法与顺序，逐条）

**顺序锁定理由**：G1 定方向 → G2 落机制 → G4 给时序，三者互为补洞、顺序不可互换（G2 依赖 G1 确认方向后才有意义；G4 时序验证依赖 G1 排除反向因果）。

### 5.1 G1 · 双向 MR + 共定位 + 重叠校正（`code/01_bidirectional_mr_coloc.R`）
- **正向**：失眠（`ukb-b-3957`）→ AD（`ieu-b-2` 主对）。
- **反向**：AD（`ieu-b-2`）→ 失眠（`ukb-b-3957`），并列跑，直接定性上下游。
- **主方法**：IVW；**敏感性方法集（锁定）**：MR-Egger、加权中位数（weighted median）、简单众数/加权众数（mode-based）、MR-PRESSO（离群检测）。
- **异质性与多效性**：报告 Cochran's Q（异质性）、Egger 截距（水平多效性）。
- **方向性加固**：Steiger 过滤（确保暴露方差解释 > 结局，排除因果颠倒）。
- **共定位**：`coloc.abf`，区域 ±500 kb 窗口，先验 P1=P2=1e-4；逐独立 lead SNP 跑，报告 **PP.H4**（主判据）与 PP.H3（共享因果变异佐证）。
- **样本重叠校正（锁定，00b 已量化）**：主对 `ukb-b-3957` × `ieu-b-2`（Kunkle/IGAP，非 UKB）**重叠≈0**，走标准 IVW/Egger/加权中位数，作主"干净"参照；复制对 `ukb-b-3957` × `ebi-a-GCST90027158`（Bellenguez）**共享 ≈87–92% UKB 个体（~426k）**，严重违反两样本 MR 无重叠假设，**必须**运行重叠稳健方法：**MRlap**（重叠校正，需暴露/结局 N 与近似遗传相关）+ **CAUSE**（区分真实因果 vs 水平多效性/共享遗传架构）+ **MR-RAPS**（稳健 SE 敏感性）。重叠量级不因精确 UKB 数而动摇，校正为强制项。

### 5.2 G2 · 血浆蛋白两步中介 MR（`code/02_protein_mediation.R`）
- **依赖 G1 方向**：仅在 G1 确认方向后执行（本设计锁定主方向 = 失眠→AD）。
- **Step 1**：失眠 GWAS → 蛋白 pQTL（UKB-PPP），得 b1。
- **Step 2**：蛋白 pQTL → AD GWAS（`ieu-b-2`），得 b2。
- **中介效应** ≈ b1 × b2（乘性近似）；间接效应 SE 用 delta 法，P 值正态近似。
- **多重检验**：~2,923 蛋白做 **FDR（BH）校正**，q < 0.05 为显著。
- **复核**：top 候选蛋白用 `coloc`（蛋白 pQTL ↔ AD GWAS，±500 kb）复核共享变异（PP.H4>0.80）。
- **反向证伪**：跑 AD→蛋白→失眠 反向两步 MR，检验"蛋白是 AD 上游"替代解释是否被排除。
- **双重 UKB 重叠缓解（00b 标记，代码已核查）**：两步中介的**主导重叠**（蛋白 pQTL ↔ AD 经 Bellenguez 的 UKB 重叠）已由 **Step2 → `ieu-b-2`（Kunkle，无 UKB 重叠）** 消除——02 主路径经 `GWAS_ID$ad` 锁定，Bellenguez 仅作 `ad_alt`、未被 02 引用（孟因之代码核查，2026-07-30）。**残余 Step1 重叠**：失眠(`ukb-b-3957`, UKB) × 蛋白(UKB-PPP, UKB) 双侧同 UKB，delta 法 SE 仍可能低估。**处置（锁定）**：delta 法为**主结果** SE；Step1 重叠以 **MRlap / bootstrap(R=1000)** 作**真实 R 环境敏感性分析**（休眠钩子，默认关闭；仅当 MRlap 已安装且显式开 Flag 时跑，未安装则跳过并披露），不计入主结果；蛋白 pQTL 若有非重叠源（SCALLOP/AGA）作额外敏感性复制。该残余重叠须在 Methods/Limitations 显式披露。

### 5.3 G4 · 多状态发病顺序模型（`code/03_multistate_onset.R`）
- **数据（UKB 个体级，需权限）**：失眠 = 自评字段 2245/2255 + 住院 ICD-10 **G47.0**；AD/痴呆 = 住院 ICD-10 **F00/G30** + 死亡登记；协变量见 §4。
- **状态（illness-death）**：S0 健康 → S1 仅失眠 → S3 共病；S0 → S2 仅 AD → S3；+ 死亡（各状态可转入的吸收态）。
- **模型**：连续时间多状态 Markov 模型（`msm` 包，辅以 `mstate`）；以**年龄**为时间尺度，处理基线快照左截断。
- **核心对比**：经 `1→3`（失眠先发）vs `2→3`（AD 先发）到达 S3 的累积发病/转移概率；到达 S3 后按进入路径分层的全因死亡生存（左截断 Cox，log-rank）。
- **协变量**：见 §4 锁定表。

## 6. 阈值与决策规则（锁定值）

| 分析 | 阈值 | 检验类型 | 备注 |
|------|------|----------|------|
| GWAS 工具筛选 | p < 5e-8（genome-wide）；clump r²<0.001 / 10 Mb / MAF≥0.01 | — | 用于 IV 遴选，非 MR 效应判据 |
| 弱工具 | **F > 10**（敏感性升 20） | — | 已核验 F 均值 38.45、最小 29.74 → 无弱工具 |
| G1 MR 效应（IVW/Egger/WM/Mode） | α = 0.05 | 双侧 | 主判据 IVW；敏感性方法一致性佐证 |
| 共定位 | **PP.H4 > 0.80**（主）；PP.H3 作共享变异佐证 | — | 逐独立 lead SNP |
| G2 蛋白中介 | **FDR q < 0.05**（BH，~2,923 蛋白） | 双侧 | 间接效应 b1×b2 |
| G4 双路径对比（转移概率） | α = 0.05 | 双侧 | 1→3 vs 2→3 |
| G4 分层生存 HR | 95% CI 不跨 1 | 双侧 | 失眠先发 vs AD 先发预后 |
| 方向性综合判定 | 双向 MR + coloc + 生物学先后 + MRlap/CAUSE/MR-RAPS | — | 见下 |

**方向性综合判定规则（预锁定）**：
- 判定"失眠→AD"为因果方向，须同时满足：(a) 正向 MR IVW P<α 且反向 MR IVW P≥α；(b) coloc PP.H4>0.80 且方向一致；(c) Steiger 通过；(d) 重叠复制对（Bellenguez）上 MRlap/CAUSE/MR-RAPS 指示真实因果而非重叠/多效性伪影（主对 ieu-b-2 无重叠，作干净参照）。
- 若**双向均显著**（正向与反向 IVW P 均<α）→ 判定为互为因果/反馈环，如实报告，不强行指定单一方向。
- G4 临床时序作为方向判定的**独立观察性确认**，不单独决定方向，但与 G1 冲突时触发"不一致"分支（§2）。

**阴性结果处理（锁定）**：若 G1 正向 MR 不显著（P≥α），如实报告"未发现失眠→AD 遗传因果证据"，并在 Discussion 讨论功率/反向因果/多效性可能；**不进行事后亚组挖掘以寻找阳性子集**（p-hacking 红线）。

## 7. 敏感性分析清单（锁定，方法学审稿生死线）

### G1 双向 MR
- MR-Egger 截距（水平多效性）
- MR-PRESSO 离群检测 + 留一法（leave-one-out）
- 异质性 Cochran's Q
- 加权中位数 / 加权众数
- Steiger 方向性过滤
- 共定位 PP.H4（每个显著位点）
- **样本重叠（仅 Bellenguez 复制对，重叠≈87–92%）**：MRlap（重叠校正）+ CAUSE（因果 vs 多效性区分）+ MR-RAPS（稳健 SE 敏感性）

### G2 蛋白中介
- 反向两步 MR（AD→蛋白→失眠，证伪）
- 仅保留强 pQTL（F > 20）
- coloc 复核 top 蛋白（蛋白 pQTL ↔ AD GWAS 共享变异）
- PhenoScanner v2 排除与失眠/AD 均多效的蛋白
- Steiger 方向过滤（step2 蛋白→AD 方向验证）
- Step1 残余 UKB 重叠敏感性：MRlap / bootstrap(R=1000) 真实环境敏感性（**delta 法为主结果 SE**）；未安装则跳过并在 Limitations 披露

### G4 多状态
1. 仅住院 ICD 失眠定义（替代自评，提高特异性）
2. 全因痴呆（F00–F03）替代 AD（F00/G30），扩大事件数
3. 逐一剔除 APOE ε4 / 抑郁 / 安眠药的似然比检验（LRT）
4. 竞争风险：死亡已作吸收态内置；补充 Fine-Gray 模型对照
5. 进入年龄分层（<65 vs ≥65 岁）

### 全局（样本重叠 + 跨祖先）
- 主对用无 UKB 重叠 AD 源（`ieu-b-2`，重叠≈0）作主分析、含重叠 Bellenguez（≈87–92%）作复制
- MRlap / CAUSE / MR-RAPS 重叠校正与多效性区分**仅作用于 Bellenguez 复制对**（主对无 UKB 重叠，无需校正）
- **跨祖先**：G3 用 CHARLS / BBJ / 东亚 UKB 子集独立复制 G1/G2（见 §8），作为 generalizability 与"全欧裔"短板缓解

## 8. 预期证据等级与升 A 缺口

**证据等级阶梯**：
- 单方法（仅 G1 或仅 G4）= 观察/遗传相关/因果，证据等级有限；
- G1+G2+G4 **三角一致收敛** = 多方法独立证据链闭合，证据等级升至"多方法三角一致的因果"，为顶刊最买账形态（Acta Neuropathologica / Molecular Psychiatry / Biological Psychiatry 等）；
- 三角**不一致** = 纠偏型高分（失眠或系 AD 临床前标记），同样可投顶刊，且更能抵御"可改变靶点"叙事夸大质疑。

**升 A 三处工程假设（STORM 审计标记，00b 核验更新）**：
1. 蛋白 panel 覆盖 GFAP / NfL / CRP / IL-6 —— **已确认**：均在 UKB-PPP（Olink Explore 3072，2,923 蛋白）面板内（Sun et al. Nature 2022/2023；文献确认）。
2. instrument 数 + 样本重叠比例 —— **已核验**：`ukb-b-3957` ↔ Bellenguez 重叠 ≈87–92%（~426k UKB 个体），严重违反无重叠假设 → MRlap/CAUSE/MR-RAPS 强制；`ukb-b-3957` ↔ `ieu-b-2` 重叠≈0（干净参照）。详见 `00b数据核验清单_失眠AD.md`。
3. 真实 P 值 FDR（G2 实测，方法已锁定 BH<0.05）—— **待 G2 本地跑数**。

**G3 跨祖先复制（后续/并行增量，非本预注册主分析）**：
- 用 CHARLS（华裔）、BBJ（日裔）、东亚 UKB 子集复制 G1/G2；
- 目的：缓解"全欧裔"generalizability 短板，避免被审稿人一票否决；
- G3 独立预注册于 `G3跨祖先复制方案.md`，不计入本 Phase 1 三角验证主判定，但扩展 Fig 5。

**残余短板（主动披露，写进 Discussion）**：
- 失眠 UKB 自评弱 → ICD 住院敏感性 + 遗传工具（独立于自评）缓解；
- 蛋白单时间点 → 遗传 MR 自带时间锚（配子→终生）缓解；
- 全欧裔 → G3 跨祖先复制作并行增量；
- G4 事件数不足（AD 发病率低）→ 全因痴呆扩样本敏感性 + 事件数预检查（<50 例转移则 msm 不稳定，须 fallback）。
- G2 Step1 残余 UKB 重叠（失眠×蛋白均 UKB）：主导重叠已由 Step2→ieu-b-2 消除，残余 Step1 重叠以 MRlap/bootstrap 真实环境敏感性缓解，并在 Limitations 显式披露（delta 法为主结果）。
