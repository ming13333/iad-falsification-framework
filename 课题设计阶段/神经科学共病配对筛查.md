# 神经科学方向 · 公共数据库疾病配对筛查

> 目标：为"多方法 × 多数据库、无湿试验、无临床治疗"的共病分析，筛出**有遗传工具（MR 可行）+ 有大队列（观察可行）+ 新颖性甜点**的神经疾病配对。

## 一、筛查方法与网络实况（先看这段）

- **实际可达库**：NCBI PubMed / E-utilities（`eutils.ncbi.nlm.nih.gov`，已验证返回 200）。
  - 对每个候选神经疾病，取三项真实计数作为代理指标：
    - **GWAS 量** = `"(疾病) AND genome-wide association"` 的 PubMed 篇数 → 代理"有无遗传工具、MR 是否可行"（越高=工具越足）。
    - **共病量** = `"(疾病) AND (comorbidity OR multimorbidity)"` 篇数 → 代理"共病方向红海程度"（越高=越拥挤）。
    - **MR 量** = `"(疾病) AND Mendelian randomization"` 篇数 → 代理"MR 因果方向已被做烂的程度"（越低=越空）。
- **被网关挡住的库**（沙箱只放行根域、API 路径 404，非本机问题）：IEU OpenGWAS / EBI GWAS Catalog REST / FinnGen REST。
  - 这些库 IEU 本身聚合了 GWAS Catalog + FinnGen + UK Biobank；**结论可由领域共识 + 上方 PubMed 代理补足**。
  - 若你本地能直连（R + `TwoSampleMR` / `ieugwasr`），可拉取精确 instrument 数与样本量，做最终可行性确认。
- **补充可行性维度（领域共识，非实时查询）**：UK Biobank 对所有主流神经疾病均有可用病例与 ICD 编码；GWAS Catalog / FinnGen 已收录全部主流神经疾病 → **MR 双向基本都可行**。真正的瓶颈是"病例功率"与"新颖性"，而非"有无工具"。

**筛选逻辑（对照指南第八节四把尺子）**：
- GWAS 量大 + MR 量小 = **甜点**：有工具但因果共病尚不拥挤 → 优先。
- GWAS 量大 + 共病/MR 都大 = 红海，须加"新角度"（顺序效应、蛋白中介、跨祖先）才出彩。
- GWAS 量小（Huntington / TBI / cSVD / 周围神经病）= MR 工具弱 → 改走**观察 + 多状态轨迹**路线，不做 MR 主打。

## 三、推荐疾病配对（按优先级，共 12 对）

### A 组 · 首选冲高分（机制强 + MR 双向可行 + 新颖性甜点）

**1. 帕金森病 ↔ 抑郁（或焦虑）**
- 机制：中脑多巴胺 + 缝际核 5-HT 通路共享；抑郁是 PD 核心非运动症状，且常先于运动症状出现。
- 可行性：PD、MDD 的 GWAS 工具均充足；UKB / FinnGen 都有表型。MR 量中等（304 / 544）→ 未饱和。
- 范式：双向两样本 MR（抑郁→PD？PD→抑郁？）+ 共定位 + 中介 MR（炎症因子 / 单胺代谢物）+ UKB 观察验证 + 按"发病顺序"分层的多状态轨迹。
- 库：观察=UKB；MR 工具=GWAS Catalog(ieu-a) / FinnGen；复制=FinnGen 或 UKB 独立亚群。

**2. 失眠 ↔ 阿尔茨海默病 / 痴呆**
- 机制：睡眠依赖的 Aβ / tau 清除受损；慢性失眠→神经炎症。
- 可行性：失眠 GWAS 工具极强（UKB 失眠 GWAS ~3 万例）；AD GWAS 极大（IGAP）。MR 量 428 但"方向之争"（失眠→AD 还是反向）仍开放 → 甜点。
- 范式：双向 MR + 多基因评分 + 中介（Aβ/tau 相关血浆蛋白）+ UKB 认知衰退轨迹。
- 库：同上；血浆蛋白可用 UKB 蛋白组（Olink）。

**3. 偏头痛 ↔ 痴呆 / 认知衰退**（优于"偏头痛↔卒中"，后者 MR 更拥挤）
- 机制：血管内皮功能、皮质扩散性抑制、共享血管危险因素；有先兆偏头痛是认知下降风险因子。
- 可行性：偏头痛实际有大型 GWAS（~6 万+ 例）；痴呆 GWAS 极大。偏头痛-痴呆 MR 明显少于偏头痛-卒中 → 选痴呆更甜。
- 范式：MR + 共定位 + UKB 多状态（偏头痛→认知衰退轨迹）+ 按先兆亚组分层。

**4. 多发性硬化 ↔ 抑郁**
- 机制：中枢神经炎症、病灶负荷、神经轴突损伤的共同通路。
- 可行性：MS、MDD GWAS 均充足；MR 量中等（389）→ 可做。
- 范式：MR + 中介（神经炎症标志物）+ 分层（按病程/病灶负荷）。

**5. 精神分裂症 ↔ 2 型糖尿病 / 卒中（重性精神病的躯体共病）**
- 机制：抗精神病药、共享免疫/代谢遗传、生活方式；SMI 躯体共病是高死亡率主因，公共卫生意义大。
- 可行性：SCZ GWAS 极足（3359）；T2D / 卒中 GWAS 极足。MR 活跃但仍可发（尤其卒中方向）。
- 范式：MR + 多状态（精神→躯体轨迹）+ 外部验证 + 指南/公共卫生 framing。

### B 组 · 稳健可发（经典但加新角度即出彩）

**6. 抑郁 ↔ 阿尔茨海默病 / 痴呆**——经典红海；破局点：①明确因果方向（抑郁是否加速痴呆）；②蛋白中介（GDF15 / 炎症）；③跨祖先验证。
**7. 卒中 ↔ 抑郁（卒中后抑郁）**——经典；破局点：MR 方向 + "首病 5 年早窗"监测。
**8. 癫痫 ↔ 抑郁 / 精神病**——共享神经递质/网络；MR 中等，可做。
**9. 成人 ADHD ↔ 抑郁 / 肥胖**——成人 ADHD 共病欠研究（共病量高但多为描述）→ MR 空间大。
**10. 孤独症 ↔ 癫痫**——共享遗传极强（如 SCN 通道、PTEN）；MR 双向可行。

### C 组 · 观察 / 轨迹优先（MR 工具弱，改走多状态模型）

**11. 创伤性脑损伤 ↔ 痴呆 / 帕金森病**——TBI GWAS 工具极少（MR 量 18）→ 不做 MR 主打，改 UKB 多状态轨迹刻画"TBI→神经退行"时序 + 敏感性分析；公共卫生/法务热度高，易上新闻向期刊。
**12. 脑小血管病 ↔ 抑郁 / 痴呆**——影像表型（UKBB MRI）丰富、机制清晰，但 GWAS 工具少 → 观察 + 影像 + 轨迹路线。
**（备选）ALS ↔ 额颞叶痴呆**——共享 TDP-43 / C9orf72；机制顶级但罕见、功率低 → 仅作假设生成，不宜独挑大梁。

## 四、Top 3 起手推荐（若只选三个）

1. **帕金森病 ↔ 抑郁**：工具足、机制干净、临床可行动（PD 人群抑郁筛查）、MR 未饱和——最稳的"冲 Nat Commun / 专业顶刊"组合。
2. **失眠 ↔ 阿尔茨海默病**：热点中的开放方向（睡眠-认知）、工具极强、蛋白中介可落地——容易讲"早期监测/干预"转化故事。
3. **偏头痛 ↔ 痴呆**：相对被低估的血管-认知轴，MR 甜点，UKB 轨迹好做。
