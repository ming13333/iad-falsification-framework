# Scoping Review：失眠–认知（阿尔茨海默病/痴呆）孟德尔随机化研究的结论分布与缺口地图

> 目的：系统清点"失眠 ↔ 阿尔茨海默病/认知"方向已有的孟德尔随机化（MR）证据，刻画结论分布，并用一张"研究缺口地图"坐实**本方向仍未被占领的增量空间**（即你下一步研究的落脚点）。
> 检索日期：2026-07-18
> 数据库：**PubMed / MEDLINE**（E-utilities，免费可达）。Scopus 网络可达但本机未配置 API key，无法拉引文量；MEDLINE 已覆盖 MR 遗传学主要文献，不影响结论/缺口判定（详见"局限"）。

## 2. 结论分布（核心发现）

### 2.1 失眠/睡眠 → AD/痴呆（前向 MR）：结论**不一致、且分裂**
| 结论 | 代表文献 | 要点 |
|------|---------|------|
| **阴性/弱**（失眠→AD 不成立） | Anderson 2021 (PMID 33150399, *Int J Epidemiol*) | 多睡眠性状（含失眠）→AD，**"几乎无证据支持因果"**；仅白天小睡有提示性保护 |
| **阳性**（失眠→AD 风险升高） | Guo 2026 (PMID 42298291, *Alzheimers Dement*)；Xiang 2024 (PMID 38865787, *Sleep Med*)；Guo 2024 (PMID 38350061, *Neurology*) | 失眠遗传易感性→AD 风险升高（如 OR≈3.02），但多变量调整后多被**削弱/衰减** |
| **小效应**（睡眠时长→认知） | Henry 2019 (PMID 31062029)；Guo 2025 (PMID 40834019, *PLoS One*) | 短睡眠时长轻微损害反应时/记忆；失眠本身效应更弱 |

> 关键观察：**同一"失眠→AD"关系，不同研究结论从"无因果"到"OR≈3"跨度极大**——这恰恰是反向因果与横向多效性未受控的信号，也是你研究的入口。

### 2.2 反向（认知/AD → 失眠/睡眠）：**稀疏但已冒头**
- Du 2025 (PMID 41296471)：多组学证据提示**神经认知下降本身是睡眠障碍的因果驱动**（反向 MR）。
- Han 2026 (PMID 41804490, *Health Sci Rep*)：明确做**失眠 ↔ 海马体积双向 MR**，并指出"失眠与海马亚区体积的双向因果此前未被解决"。
- Li 2022 (PMID 36031898)：白天小睡 ↔ AD 双向 MR（非失眠本体）。

> **失眠 ↔ AD 的"直接双向同时定性"目前无人完成**——现有双向研究要么用替代睡眠表型（小睡），要么只到脑结构（海马）而非 AD 临床结局。

### 2.3 蛋白/多组学中介：**兴起但均非"失眠→蛋白→AD"**
- Chen 2026 (PMID 42277229, *Mol Psychiatry*)：睡眠性状血浆蛋白组，遗传优先蛋白（方法是"失眠→蛋白"，但**未以 AD 为结局做两步中介**）。
- Li 2026 (PMID 41912985, *Alzheimers Dement*)：睡眠障碍 + CSF Aβ + 蛋白模块，MR 支持睡眠→多个蛋白（ADNI 样本，**非 UKB 大队列两步中介**）。
- 元分析层面：Wang 2026 (PMID 41517697) 汇总 51 篇睡眠 MR，确认失眠→AD 关联存在但异质。

### 2.4 祖先 / 时序
- **祖先**：全部为欧裔（UKB / FinnGen / IGAP / PGC）。**零篇**东亚（CHARLS / BioBank Japan）/跨祖先验证。
- **时序（多状态/发病顺序）**：MR 文献中**完全缺席**；仅观察性有 Yuan 2022（睡眠时长+遗传易感+AD 纵向 UKB）。**MR 与多状态顺序模型的组合为零**。

| STORM/指南第七、八节规划的要素 | 文献是否已占 | 你的落点 |
|------|------|------|
| 双向两样本 MR（UKB↔FinnGen） | 部分（用替代表型） | **首次对"失眠↔AD"做直接双向** |
| 共定位检验 | 空白 | **补齐，回应怀疑者的"连锁假象"质疑** |
| 蛋白中介 MR（UKB 蛋白组） | 空白（近似有） | **失眠→血浆蛋白→AD 两步中介，给出机制候选** |
| UKB 多状态顺序模型 | 空白 | **先失眠 vs 先认知下降的预后差**（范式平移） |
| 第二独立队列复制 | 部分 | **加跨祖先（CHARLS/BBJ）复制 → generalizability** |
| 预注册 + 协变量控制（抑郁/教育/安眠药） | 多数有但不统一 | 强制纳入，堵住方法学审稿人枪眼 |

**一句话研究问题（建议）**：
> "失眠与阿尔茨海默病之间的因果方向、时序与蛋白机制是什么？——一项基于双向 MR、共定位、血浆蛋白中介与多状态发病顺序模型的跨祖先研究。"

这句话把叙事从"第 N 篇证明失眠→AD"挪到"**首次干净定性方向/顺序 + 机制候选 + 跨祖先**"的高地，直接避开同质化 MR 的拒稿区。

## 5. 立题可行性快速复核（对照指南第八节四把尺子）
- **机制 plausibility**：炎症 / glymphatic / 共享遗传 → 强（文献普遍支持）。
- **可行性**：失眠（Jansen 2019 ~130万）、AD（Bellenguez 2022 >10万）工具充足；UKB 血浆蛋白组可作中介 → 强。
- **跨库可比**：UKB+FinnGen 欧裔可作主分析；CHARLS/BBJ 跨祖先复制待实测 GWAS 可及性（建议下一步用 `TwoSampleMR` 拉 instrument 数确认）。
- **新颖性缺口**：🔴 五格空白已实证坐实 → 强 novelty。

## 6. 局限（方法学诚实声明）
1. 仅检索 PubMed/MEDLINE（Scopus 因缺 API key 未纳入引文量；网络可达，配置 key 后可补）。
2. 仅英文、摘要级筛选，未做全文偏倚风险（RoB）与质量评分（如 MR-Robust 工具）。
3. 结论编码基于摘要，少数论文（如 42298291 多变量后效应）需全文确认衰减幅度。
4. 未做引文网络分析（被引次数）量化"研究热度"，但 2024–2026 发文密度本身已说明该方向处于上行周期。
