# 失眠 ↔ 阿尔茨海默病/认知 · 孟德尔随机化 Scoping Review（三库合并版）

> 三数据库 PRISMA-ScR：PubMed + Scopus + Web of Science。
> 目的：系统清点失眠/睡眠↔AD/认知的 MR 与因果证据、结论分布，并**用第二、第三库交叉验证"研究缺口地图"，坐实你的增量**。
> 方法学：三库分别检索 → 按 DOI→PMID→标题归一化去重 → 严格筛选（MR+睡眠+认知三词共存，WoS/PubMed 用全文摘要，Scopus 用标题+PubMed 摘要充实）→ 缺口定向验证。

## 二、结论分布（三库合并后）

- **失眠→AD 单向 MR：结论仍分裂**（与之前一致）
  - 阴性："几乎无因果证据"（Anderson 2021, *Int J Epidemiol*）
  - 阳性但衰减：Guo C 2026（*Alzheimers Dement*）OR≈3.02，多变量 MR 后效应衰减
  - 阳性：Xiang 2024；Wang ZL 2025（*Medicine*，失眠→认知下降 β=-0.015，RTI 中介 15.4%）— 新方法（2-step MVMR）但欧洲祖先、单库
- **睡眠性状→认知**：小效应较一致（睡眠时长/日间嗜睡/日间小睡→认知），但非失眠本体
- **反向（AD→失眠）**：稀疏冒头（Du 2025；Han 2026 失眠↔海马体积双向）— **失眠↔AD 直接双向定性无人做**
- **蛋白中介**：有"睡眠性状→血浆蛋白"组学（如 2026 *Mol Psychiatry* 睡眠性状血浆蛋白质组），但**无"失眠→血浆蛋白→AD"两步中介**
- **多祖先**：极稀 — 多数 MR 用欧洲祖先 UKB/FinnGen；非欧裔睡眠→AD MR 几乎是空白
- **时序/多状态**：全部为观察性纵向或少数 MR；**多状态发病顺序模型完全缺席**

## 三、更新后的"研究缺口地图"（红区修正判定）

> 用 WoS **全文摘要**重新验证后修正：原 Scopus 标题法得出的"全空"偏严——缺口**并非字面为零**，但**特定于"失眠↔AD"组合**的缺口依然成立。修正判定如下。

| 缺口（你的潜在增量） | Scopus 标题法 | WoS 摘要法（修正） | 最终判定 |
|---|---|---|---|
| **G1 双向因果定性**（失眠↔AD） | 8 篇（无直接双向） | 54 篇睡眠-认知双向 MR，其中**失眠+AD 特定仅 11 篇**，且无一为"失眠↔AD 直接双向 MR" | 🟡 方法成熟、**特定配对空缺** |
| **G2 蛋白两步中介**（失眠→血浆蛋白→AD） | 3 篇（无两步） | 61 篇提及蛋白，其中**失眠+AD 特定仅 6 篇**，无"失眠→蛋白→AD"两步 | 🔴 仍空 |
| **G3 多祖先验证**（东亚/华裔/日裔等） | 0 篇 | 26 篇，其中**失眠+AD 特定仅 6 篇**，非欧裔睡眠→AD MR 极稀 | 🔴 最强缺口 |
| **G4 时序/多状态顺序模型** | 11 篇（无多状态） | 76 篇，其中**失眠+AD 特定 13 篇**，均为观察性纵向/综述，**多状态顺序模型缺席** | 🔴 仍空 |

**结论**：没有任何一篇同时交付 **"双向 MR + 共定位 + 血浆蛋白两步中介 + 多祖先验证 + 多状态发病顺序"** 这五个要素。这个**组合包**就是你的增量——而非其中任何单一方法（单一方法都已被做过）。

## 四、你的增量（坐实）

> 立题一句话（更新版）：
> **"失眠与阿尔茨海默病之间的因果方向、时序与蛋白机制是什么？——一项基于双向 MR、共定位、血浆蛋白中介与多状态发病顺序模型的跨祖先研究。"**

这句话把叙事从"第 N 篇证明失眠→AD"挪到"**首次以组合包干净定性方向/顺序 + 机制候选 + 跨祖先**"高地，避开同质化 MR 的拒稿区。

**优先级建议（性价比排序）：**
1. **多祖先验证（G3）**——最空、最易出彩、正面怼"generalizability"审稿意见（用 CHARLS / BBJ / 东亚 UKB 子集）。
2. **血浆蛋白两步中介（G2）**——用 UKB 血浆蛋白组做"失眠→蛋白→AD"两步 MR，机制落地。
3. **多状态顺序模型（G4）**——UKB 内刻画"先失眠→后 AD"vs"反向"的发病顺序与预后。
4. **双向 MR + 共定位（G1）**——与上面打包，定性方向。

## 五、文献计量速览（可选）

- 三库并集 821 篇，年度发文量随 MR 方法热度在 2019 后陡增。
- 高被引代表：*Lancet Neurol* 2018 类淋巴通路（1372）、*Science* 2020 类淋巴衰竭（897）、睡眠-认知双向关系综述等——说明"睡眠-认知"是持续热点，但**方法学创新（多祖先+多状态+蛋白中介组合）尚未被高引论文占据**。
