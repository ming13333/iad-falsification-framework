# De-AI pass — 2026-11-02

Two documents were reviewed: the manuscript source
(`课题设计阶段/manuscript_Frontiers_Methods_v2_humanized.md`) and the response letter
(`reviews/Response_to_Reviewers_Frontiers.md`).

The pass was measured, not estimated. `code/detect_ai_style.py` reports sentence
rhythm, sentence-opening connectives, abstract vocabulary, em-dash pairs and
overclaiming; `python code/detect_ai_style.py FILE` reproduces every number below, and
`--compare BEFORE AFTER` prints the two side by side.

## Two bugs in the first version of the detector, both of which flattered the text

Recorded because the first two runs produced a list of "long sentences" that was wrong,
and a wrong list would have produced wrong edits.

1. **Merged blocks.** Splitting paragraphs on blank lines only folded bulleted lists
   and headings into the paragraph above, so `Core R packages and roles.` plus five
   bullets was counted as one 117-word sentence. Fixed by treating each line as a
   paragraph.
2. **Abbreviations matched by substring.** `ed.` was in the abbreviation list, and a
   plain `str.replace` fired inside `specified.`, so that sentence never ended and
   swallowed the next one. The same routine masked every capital-plus-period, which
   turned `Grade C. The total …` into a single 115-word sentence. Both are fixed by
   word-boundary matching and by masking initials only where they are provably
   initials (`Smith, J. C.`).

After the fixes the manuscript had **5** sentences over 70 words, not 11. Editing
against the first number would have been work done to satisfy a measurement error.

## What was changed

Manuscript, six edits, all inside paragraphs the revision had already altered for a
reviewer:

1. `Effect sizes of 0, 0.08 and 0.15 …` (89 words, three semicolon clauses) split into
   two sentences at the point where the design rationale starts.
2. `Moving any single cutoff by one point …` (94 words) split into three, one per
   boundary being tested.
3. `the annotated clumped instrument set contains no variant …` — the em-dash pair
   became a colon plus a new sentence; the clause inside it already carried a
   parenthetical table reference, so brackets would have nested.
4. `A causal claim is the hypothesis under test — for instance, … — and is` → the pair
   became brackets.
5. `reported tier by tier — unclumped, … — so that` → brackets.
6. `supported by these data — not that the true effect is exactly zero` → comma.

Response letter, eight edits: three sentence splits (the 72-word R3-4 paragraph, the
78-word cut-off paragraph, the 81-word closing concession) and five em-dash pairs
converted to brackets, a colon, a semicolon or commas.

**No number changed in either document.** Verified by diffing the multiset of numeric
tokens against `HEAD`: the letter is identical, and the manuscript differs only by the
removed Popper DOI and the word-count declaration (8,372 → 8,374).

## What was deliberately left alone

**The 46 `rather than` constructions in the manuscript (3.6 per 1,000 words) and 49 in
the letter (5.0).** This looks like a tic and reads like one, but on inspection almost
every instance carries the contrast the sentence exists to make — *instrument count
rather than biological signal*, *a screening instrument rather than a confirmatory
test*, *insufficient evidence rather than evidence against*. The paper is an argument
about what a result does **not** show. Substituting synonyms for the contrast would
have been cosmetic churn that blurred distinctions the reviewers specifically asked to
have sharpened. Two instances were removed where the same paragraph used the
construction twice.

**The 104-word sentence in the Introduction** (four systematic distortions, `(i)` to
`(iv)`). It is the single worst offender in the document, and it sits in a paragraph
that is byte-identical to the submitted version. Editing it would create a change no
reviewer comment explains, which is the one property this revision has maintained
throughout: every altered passage is either highlighted as an answer or listed with a
reason. It is flagged here instead, so the choice is explicit rather than overlooked.
A clean copy-edit pass over the whole manuscript — not just the revised parts — would
handle it, at the cost of that guarantee.

**The 85-word rubric sentence** (`Score: 2 only if …; 1 where …; 0 where …`). The
parallel structure is the rubric's own convention and appears identically at every
gate; breaking it for rhythm would make the gates harder to compare.

**The abstract at 377 words.** Already decided: leave it unless an editor asks.

## The disclosure question

Journal policy asks that generative-AI assistance be disclosed, and it is — the
manuscript's *Use of AI* statement was widened this revision to say that the models
re-executed and cross-checked computations and rebuilt the S8 scoring table, not merely
that they edited language. Nothing in this pass changes that statement; it corrects
prose, not authorship.
