## 3. 准确性（Accuracy）—— 存在 3 项需处理点

### 3.1 坐标体系不一致（重要）
| 数据 | 真实 build | 依据 |
|------|-----------|------|
| ieu-b-2 | **GRCh37** | VCF `##contig … assembly=HG19/GRCh37` |
| ukb-b-3957 | **GRCh37** | VCF `##contig … assembly=GRCh37` |
| Bellenguez | **GRCh38** | meta `genome_assembly: GRCh38`；`variant_alternate_id` 用 `chr1:…` 前缀 |

→ 两个 VCF 同为 GRCh37，可**直接 harmonize**；Bellenguez(GRCh38) 与二者**坐标系不同**，MR 前必须 liftover（GRCh38→GRCh37）或作为独立的 GRCh38 复制分析。

### 3.2 染色体命名一致
- 三组数据在**分析列**中均为数字 `1..22`（无 `chr` 前缀）：VCF 的 `#CHROM`，TSV 的 `chromosome` 列。✅ 可直接对齐（仅 Bellenguez 的 `variant_alternate_id` 辅助列带 `chr` 前缀，解析该列时才需注意）。

### 3.3 MR 必需列齐全
- **VCF（ieu-b-2 / ukb-b-3957）**：`ID`(rsid)、`#CHROM`、`POS`、`REF/ALT`、`FORMAT=ES:SE:LP:…`（ES=beta、SE、LP=-log10 p）→ ✅ 满足 TwoSampleMR `read_vcf`。
- **TSV（Bellenguez）**：`variant_id, chromosome, base_pair_location, effect_allele, other_allele, beta, standard_error, p_value, n_cases, n_controls, …` → ✅ 列完备。

### 3.4 样本量未内嵌（用法注意）
- 两个 **VCF 均不含 n / ncase / ncontrol**（FORMAT 仅 ES:SE:LP[:AF]:ID）→ 运行 MR / coloc 时必须从研究元数据**注入样本量**：Kunkle 2019 = 21,982 病例 / 41,944 对照（n=63,926）；UKB 失眠 n 取 ukb-b-3957 元数据。
- Bellenguez TSV **含逐位点 n_cases / n_controls** → ✅ 可直接用于 MR。

### 3.5 重复 rsID（需去重）
| 数据 | 总记录 | 唯一 rsID | 重复行数 | 占比 |
|------|--------|-----------|----------|------|
| ieu-b-2 | 10,528,610 | 10,444,926 | **83,684** | 0.79% |
| ukb-b-3957 | 9,851,866 | 9,837,128 | **14,738** | 0.15% |
| Bellenguez | 21,101,114 | 21,070,466 | **30,648** | 0.145% |

→ 三组数据均存在非唯一 rsID。MR / coloc 前须**按 rsID（或 chr:pos）去重**，建议保留每 rsID 中 p 最小（最显著）的记录，否则 `harmonise_data` 会因非唯一 SNP 报错或产生歧义 harmonization。
- ieu-b-2 另有 **75 行 rsID 为 `.`**（缺失，占比可忽略）。

### 3.6 标签小瑕疵
- `ieu-b-2/README.txt` 内容实为 **Bellenguez / GRCh38** 描述（错贴），但 VCF 头已确认其为正确的 Kunkle 2019 GRCh37。属文件夹标签混淆，提醒后续勿凭 README 判断 build。
